# ToolDrop

A fast, static, mobile-friendly directory of AI tools — plain HTML/CSS/JS, hosted free on GitHub Pages.
Live: https://tooldrop-ai.github.io/

## How it works
`tools.json` is the single source of truth. `scripts/build.py` (Python 3, stdlib only) pre-renders every page
so content is crawlable without JS; `app.js` adds search, category and pricing filters (also `?q=` search URLs).

Generated by the build: `index.html` (sponsor slot, *New this week*, all tools, submit form), `category/*.html`,
`advertise.html`, `404.html`, `sitemap.xml`, `feed.xml` (RSS), `robots.txt`. Don't edit those by hand — edit `scripts/build.py`.

## Add a tool (daily update)
```bash
python3 scripts/add_tool.py "Name" "https://official.url/" "One-line description." "Coding" freemium
git add -A && git commit -m "Add Name" && git push
```
The script checks the URL responds, rejects duplicates, sets `date_added` to today, and rebuilds.
Or edit `tools.json` manually and run `python3 scripts/build.py`. Pricing: `free` | `freemium` | `paid`.
"New this week" = tools added within 7 days of the newest `date_added`.

## Submissions & sponsors (no backend)
The submit form and the Advertise button open pre-filled GitHub issues using `.github/ISSUE_TEMPLATE/`.
Review issues labelled `submission`/`sponsor`, then add via `add_tool.py`.

## Local preview
Asset paths are root-absolute (`/…`) so the 404 page works. Serve this folder:
`python3 -m http.server 8000` → http://localhost:8000/

## Deploy
Push to `main`; Pages serves from `main` / root (`.nojekyll` included). For a different repo name/user,
change `SITE`, `BASE` (e.g. `/repo/` for project sites) and `REPO` at the top of `scripts/build.py` and rebuild.
